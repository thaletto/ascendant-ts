# Astrotalk Moon-relative yoga source map

Source reviewed: [Astrotalk, "300 Astrology Yoga"](https://astrotalk.com/astrology-yoga), accessed 2026-08-28. This note maps every catalog rule that either reckons a placement **from the Moon**, reckons the Moon from another body, defines a mutual relative placement with Moon, or is one of the catalog's explicit lunar flanking/conjunction forms. It deliberately excludes rules that merely name the Moon's sign, house, phase, or Navamsa without a relative-placement relation.

## Catalog ambiguities that need an explicit rule-set decision

- The implementation treats every modeled planet, including Rahu and Ketu, as a planet whenever the source supplies no exclusion. Sunapha follows its explicit Sun-only exception.
- It uses `benefics` for Adhi, Vasumathi, and Amala without identifying natural versus functional benefics, and leaves the required occupancy quantifier implicit.
- It alternates `or` formulations (Vasumathi, Amala, and the Raja Yoga row) without saying whether either branch independently forms the yoga; the natural executable reading is an inclusive alternative, but that is an interpretation.
- Budha's “Moon in a kendra” and Kusuma's “Moon in the 7th” omit their references. The implementation uses Lagna for each; the fixed-Lagna Raja Yoga still does not identify “the Lord.”
- “All moon-relative” should not be expanded to every page row that mentions Moon: examples such as Garuda, Rajalakshana, and multiple health/family rows state Moon's sign, phase, or absolute house but no Moon-relative relation.
